# Litho API

[![CI Status](https://cnb.cool/kainonly/litho-api/-/badge/git/latest/ci/status/push)](https://cnb.cool/kainonly/litho-api)

一个后台管理 API 服务，包含用户、组织、角色、权限、路由、审计等基础模块。

技术栈：Go、Hertz、PostgreSQL、MongoDB、Redis、NATS。
